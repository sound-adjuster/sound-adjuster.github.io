Audio settings guide

Set a default volume in Firefox and save settings per site

A quiet online course might need a boost, while a music site might already be loud enough. Set a default for Firefox tabs and save separate audio settings for sites that need them.

By tropic · Updated 20 November 2026 · Based on Sound Adjuster 2.6.0

When should I use defaults or site settings?

These settings change the audio processed by Sound Adjuster, not your device volume or the volume knob inside a website’s player.

Site settings and defaults at a glance
What you wantUse this featureOn your next visit
A specific sound for one websiteRememberThat site restores its saved gain, balance, channels and equalizer.

Remember: a different sound for each website

If a course site is always quiet, raise Gain there and enable Remember. Your music site can keep a different level without changing the course setting.

  1. Open the website, start a supported audio or video player, and open Sound Adjuster from the Firefox toolbar.
  2. Adjust Gain, Pan, Mono, Flip L/R and the Equalizer as needed. Start near 1× and reduce gain if you hear distortion.
  3. Turn on Remember in the popup footer. Reload the page to check that your choices return.
  4. For another setup on the same website, choose Profiles → Save current… from the ⋯ menu, name it, and select it when needed.

Remember saves changes while it is on. Turn it off to stop restoring that site’s current settings; the sound in the open tab stays unchanged. Named profiles can be removed separately in Manage profiles.

Set the default audio for other tabs

Default audio settings apply to supported sites. To use different settings on a particular site, open it and turn on Remember after adjusting the sound.

  1. Open Sound Adjuster’s ⋯ menu and choose Settings and exceptions.
  2. In Default audio settings, turn on Enabled.
  3. Choose Gain, Pan, an Equalizer preset, Mono and Flip L/R, then click Save defaults.
  4. Reload a supported page or open a new tab to use the defaults. Saving them does not immediately replace the sound in tabs already open.

Turn off Enabled to stop using the defaults. The change saves automatically. Any settings saved with Remember still apply when you revisit the site.

What happens when both are enabled?

  1. A remembered setting for the current website comes first.
  2. If that site has no remembered setting, enabled global defaults apply.
  3. If neither is available, Sound Adjuster starts at neutral settings: 1× gain, centered balance and a flat equalizer.

A course, a music site and a new tab

For example, save a 1.25× global default, remember your course site at 1.75×, and remember a music site at 0.8×. Returning to the course restores 1.75×; returning to the music site restores 0.8×. A new supported site starts at 1.25×.

These are example levels, not loudness targets. Remember restores your choices; it does not automatically make different recordings equally loud.

Change the active tab without opening the popup

Keyboard shortcuts use the same audio controls in the active tab. If Remember is on for that site, shortcut changes also update its remembered settings.

  • Increase gain by 0.25×Alt+↑
  • Decrease gain by 0.25×Alt+↓
  • Reset audioAlt+Shift+0
  • Toggle monoAlt+Shift+M

To change the combinations, open Settings and exceptions → Keyboard shortcuts → Edit shortcuts. Firefox opens its extension shortcut manager. Check the assigned keys there if another shortcut conflicts.

Reset, privacy and playback limits

Reset returns the current tab to enabled global defaults, or to neutral settings when defaults are off. If Remember is on, that reset result becomes the site’s remembered setting too.

Your settings stay in local Firefox extension storage on this device; they are not synced. Remembered site settings and global defaults are not restored in private windows.

Sound Adjuster works with standard HTML audio and video. Protected playback, cross-origin media and browser restrictions may prevent processing. A saved setting cannot bypass these limits; check the popup’s availability message.
